Design system · Dusk Ember

Warm plum surfaces, one ember accent, and big rounded numbers in Readex Pro (Latin and Arabic in one family). Three rules: the number is the hero, one tap does the daily job, and nothing scolds you.

Color primitives

Semantic roles

confetti-* and wallpaper are decorative roles, used only for the celebration and the widget previews.

Contrast (WCAG 2.2 AA)

Typography

Display is for the streak number only. Arabic uses the same family. Numbers always use tabular figures so they don’t jitter when they change.

Spacing

Shape

Elevation

Cards are flat (tint, no shadow). Shadow only for the FAB, sheet, snackbar, dialog and widgets.

Icons

Material Symbols Rounded, 24 dp. Compose: material-icons-extended rounded set.

Streak card

The core component. Whole card is a button that opens the edit sheet; reset and steppers sit above it. The outline is the goal progress.

Card hit area is the full card; reset 48 dp; steppers 48 dp (minus) and 56 dp tall (plus), 8 dp apart. TalkBack reads “Gym, check-in, 12 days, 12 of 30, done today” with custom actions Check in / Undo / Reset / Delete.

Stepper buttons

Plus carries the day’s job, so it’s the filled one and has a label. Minus is quiet.

Button

One primary per view. Verbs as labels.

Height 56 dp, touch ≥ 48 dp. Loading keeps width.

Number and text field

Numbers use the numeric keyboard, accept digits only, format with the locale on blur.

Type selector, switch

Bottom sheet

Calf AdaptiveBottomSheet: Material 3 modal sheet on Android, native sheet on iOS. Drag handle, title, close. Discard confirm only if something was typed.

Snackbar, callout, dialog, celebration

Error and feedback framework

Every message lands on one surface. Decision order: decision needed or irreversible → T6; one input → T1; nothing to show → T5; lasting condition → T4; otherwise T3.

Shell & brand

There is one screen, so no navigation bar. The large title collapses into a top bar when the list scrolls. No network means no offline or sign-in states.

Adaptive icon: 108 dp canvas, artwork inside the 66 dp safe zone. Background layer = inverse-surface (plum), foreground = inverse-primary (ember). Monochrome layer = foreground only.
